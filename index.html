Najm Agent Flow

A technical walkthrough of an agent that answers, extracts and acts on industrial documents in Arabic and English, entirely inside an in-Kingdom cloud region. It shows which component is called, when, under which control, and how retrieval and the language model work together at every stage.

    11 · ERP integration
    
  
    From answering to acting
    
  
    The language model never calls ERP. It asks for an allow-listed tool; the MCP server validates the input and calls the ERP API with the user’s own permissions. Writes are staged as drafts and committed only after a named approver signs off.

      09 · Platform
      Running on OCI
      Two public OCI regions in Saudi Arabia: Riyadh as primary and Jeddah for disaster recovery. Each part of the system maps to a managed OCI service or runs on Kubernetes (OKE).

      10 · MLOps
      
  
      One gate, one loop
      
  
      Models drift even when no code changes, because the data changes. Every change, from one prompt line to a new model, passes the same evaluation gate, ships to a small share of traffic first, and is watched in production.

      12 · Machine learning
      
  
      Where ML complements the LLM
