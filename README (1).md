# Najm · Sovereign AI for Industry

Najm is a reference design and interactive walkthrough for a sovereign, Arabic-first AI agent for industrial clients. It answers questions from documents in Arabic and English, extracts data from them, and acts on them, with everything running inside an in-Kingdom cloud region.

**Live site:** https://iixazooz58-alt.github.io/najm/
